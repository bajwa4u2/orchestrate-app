# Orchestrate Asset Pipeline

Active Flutter app: `orchestrate_app`.

The app icon source is `store_assets/source/orchestrate-app-icon-master.svg`. It is a clean vector-style version of the existing Orchestrate circular workflow mark, replacing the low-resolution default Flutter platform icon outputs.

Generated outputs are created by:

```powershell
powershell -ExecutionPolicy Bypass -File tool/generate_store_assets.ps1
```

## Generated Paths

- Master PNG: `store_assets/source/orchestrate-app-icon-master-1024.png`
- Android launcher icons: `android/app/src/main/res/mipmap-*/ic_launcher.png`
- Android adaptive icon foreground: `android/app/src/main/res/drawable/ic_launcher_foreground.png`
- Android adaptive icon XML: `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
- Android adaptive icon background: `android/app/src/main/res/drawable/ic_launcher_background.xml`
- Google Play icon: `store_assets/android/play-icon-512.png`
- Google Play feature graphic: `store_assets/android/feature-graphic-1024x500.png`
- Web favicon: `web/favicon.png`
- Web PWA icons: `web/icons/Icon-192.png`, `web/icons/Icon-512.png`, `web/icons/Icon-maskable-192.png`, `web/icons/Icon-maskable-512.png`
- iOS app icon set: `ios/Runner/Assets.xcassets/AppIcon.appiconset/*.png`
- iOS App Store icon copy: `store_assets/ios/app-store-icon-1024.png`
- Windows app icon: `windows/runner/resources/app_icon.ico`
- Windows store tile: `store_assets/windows/store-tile-300.png`

## Notes

- Google Play applies rounded corners and shadows dynamically; the source icon intentionally stays square.
- Store screenshots are not generated by this script because they must reflect real authenticated app states.
- App signing, App Store provisioning, and MSIX packaging are separate release setup tasks.
