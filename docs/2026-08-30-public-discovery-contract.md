# Orchestrate public discovery contract

The canonical public host is `https://orchestrateops.com`. Its nginx boundary
serves real text robots, XML sitemap, and IndexNow ownership endpoints before
the Flutter fallback.

The sitemap is an explicit inventory of stable public product, marketing,
pricing, policy, legal, evaluator, security, and FAQ routes. Dynamic journey
state and application routes are not enumerated. Customer execution,
agreements, invoices, payments, account state, authenticated client state,
operator/admin state, and API routes are excluded.

Unknown query state never creates a new canonical document and tracking
parameters never redefine canonical identity. After a successful deployment,
`node tool/notify_indexnow.mjs` hashes the canonical sitemap and sends one
notification only when the public inventory changes.

Native continuation is product-configured at the public-web boundary. The
canonical public URL remains the only page, share, search, and future native
destination identity. The public shell exposes a quiet acquisition rail on the
stable sitemap routes when a verified store destination exists; it never
forces an install, performs installed-app detection, or redirects crawlers.

Orchestrate currently has verified Apple App Store and Microsoft Store
destinations, and a Google Play destination supplied by the accepted company
estate. Android, iOS, and Windows are therefore acquisition-eligible. Native
association/open behavior remains a separate Claude-owned implementation
dependency; until it is verified, the web rail uses `Get Orchestrate` rather
than claiming `Open in Orchestrate`.

Authenticated customer execution, agreements, invoices, payments, account
state, and operator/admin routes remain excluded. No product behavior or
private route is changed by this contract.
